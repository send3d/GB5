개인정보처리방침

시행일: 2026년 10월 8일 · 운영자: WNT 개발자 send3d

이 방침은 WNT Windows·Android 앱과 WNT 안내 홈페이지에 적용됩니다. WNT는 원고 집필, 음성 듣기, EPUB 제작 및 사용자가 선택한 저장소에서의 파일 작업을 지원합니다.

1. 원고와 작업 자료

원고, 표지, 이미지, EPUB 작업 및 앱 설정은 기기 내부 저장소와 사용자가 선택한 파일 저장 위치에서 처리됩니다. 작업 중인 자료, 복구 기록, 저장 실패 보존본 등은 앱의 기기 내부 저장소에 남을 수 있습니다.

로컬 작업에는 Google 또는 Dropbox 계정 연결이 필요하지 않습니다. 클라우드 저장을 선택하면 파일 내용과 이름 등 전송에 필요한 정보가 선택한 서비스로 전달됩니다.

2. Google Drive에서 접근하는 정보와 목적

Google Drive 연결은 사용자가 선택하여 승인하는 기능입니다. WNT는 https://www.googleapis.com/auth/drive.file 권한을 요청하며, 이 권한이 허용하는 범위 안에서 WNT로 만든 파일 또는 사용자가 WNT에 접근을 허용한 파일을 이용합니다.

Google Drive 기능에서 처리하는 정보
정보이용 목적
Google 계정의 이메일, 계정 식별자 및 제공되는 표시 이름연결한 계정을 표시하고, 다른 계정의 파일에 잘못 저장하는 것을 방지합니다.
접근이 허용된 파일·폴더의 이름, 식별자, 위치, 형식, 크기, 수정·버전 정보목록 표시, 파일 선택, 저장 위치 확인 및 파일 변경 충돌 확인에 사용합니다.
사용자가 열거나 저장하는 원고·EPUB·표지·이미지 등 파일 내용선택한 파일을 내려받아 편집하거나, 사용자가 요청한 파일을 Google Drive에 저장합니다.
인증 토큰과 연결 상태승인된 계정으로 파일 작업을 수행하고 연결을 유지합니다.

Google 계정 비밀번호는 WNT가 받거나 보관하지 않습니다. Google의 로그인 및 권한 승인 화면에서 사용자가 직접 인증합니다.

3. Google 정보의 보관과 보호

Google Drive 파일 요청은 사용자의 기기에서 HTTPS로 Google API에 전송됩니다. Google Drive 연결 기능은 작품과 계정 정보를 WNT 개발자의 별도 중앙 저장 서버에 보관하지 않습니다.

Windows 앱은 Google 연결 토큰을 해당 Windows 사용자 계정의 보호 기능으로 암호화하여 기기에 보관합니다. Android 앱은 Google Play 서비스의 권한 연결 기능을 사용하고, 계정 식별 정보는 앱 전용 저장소에 보관합니다. Android에서 인증 토큰의 캐시는 Google의 권한 연결 서비스가 관리합니다.

기기에 다운로드하거나 저장한 작품 파일과 복구 기록은 계정 연결 정보와 별도로 남을 수 있습니다. 기기의 사용자 계정, 잠금 및 백업 기능을 이용해 파일을 보호해 주세요.

4. 데이터의 공유와 사용 제한

WNT는 Google API를 통해 받은 정보를 원고와 파일 작업 등 사용자가 요청한 앱 기능에 사용합니다. 이 정보를 판매하거나 광고 타기팅, 신용 판단 또는 일반 AI 모델 학습에 사용하지 않습니다.

파일은 Google Drive 기능 수행에 필요한 범위에서 Google로 전송됩니다. 사용자가 다른 저장소로 저장·내보내기를 선택하면 선택한 저장소로 해당 파일이 전달됩니다. 사용자가 지원을 위해 직접 원고나 파일을 보내는 경우에는 그 요청의 처리에 필요한 범위에서 확인할 수 있습니다.

WNT의 Google API 데이터 이용 및 다른 서비스로의 전달은 Google API 서비스 사용자 데이터 정책과 Limited Use 요구사항을 준수합니다.

5. 연결 해제, 권한 철회와 삭제

WNT의 Google Drive 연결 설정에서 연결을 해제할 수 있습니다. Google에 부여한 권한도 철회하려면 Google 계정의 서드 파티 연결 관리에서 WNT의 접근 권한을 삭제해 주세요.

연결 해제는 Google Drive나 기기에 저장된 작품 파일을 삭제하지 않습니다. 파일은 해당 저장소에서 직접 관리·삭제할 수 있습니다. 기기 내부 작품 기록과 복구 자료는 앱의 관련 관리 기능에서 삭제할 수 있으며, 앱 데이터 초기화나 기기 파일 삭제의 영향은 운영체제와 저장 위치에 따라 달라집니다.

Google에 저장된 파일, 버전 및 휴지통의 보관·삭제는 Google의 정책과 계정 설정에 따릅니다. 로컬 파일과 별도로 만든 백업도 필요에 따라 직접 삭제해 주세요.

6. Dropbox와 음성 기능

Dropbox를 선택하여 연결하면 계정 확인, 파일 목록과 선택한 파일의 열기·저장에 필요한 정보가 Dropbox에서 처리됩니다. Dropbox에 저장된 자료의 관리에는 Dropbox 개인정보처리방침이 적용됩니다.

TTS 기능은 선택한 운영체제·브라우저·음성 엔진을 사용합니다. 음성 엔진에 따라 읽을 텍스트가 해당 제공자의 서버에서 처리될 수 있으므로, 사용할 엔진의 설정과 개인정보 안내를 확인해 주세요.

7. 안내 홈페이지와 문의

이 홈페이지에는 회원가입, 작품 업로드, 자체 방문 분석 코드 또는 광고 코드가 없습니다. 홈페이지를 제공하는 GitHub Pages는 접속 과정에서 서비스 운영을 위한 정보를 처리할 수 있으며, 해당 처리에는 GitHub 개인정보처리방침이 적용됩니다.

이메일로 문의하면 발신 이메일 주소, 문의 내용 및 직접 첨부한 자료가 문의 대응을 위해 처리됩니다. 문의 처리와 관련한 정보의 열람·삭제 요청은 아래 연락처로 보내 주세요.

8. 변경 안내 및 연락처

처리하는 정보나 이용 목적이 바뀌면 이 페이지와 필요한 앱 내 안내를 갱신합니다. Google 사용자 데이터의 새로운 이용 목적에 동의가 필요한 경우 해당 이용 전에 안내하고 동의를 받습니다.
